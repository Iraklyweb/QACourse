# QA Конспект

Статическая учебная библиотека из двух локальных выгрузок Kata Academy: «Ручное тестирование» и «MQA Base».

В публичную сборку входят только очищенные страницы, навигация и локальный поисковый индекс. Исходные JSON, служебные скрипты выгрузки, данные сессии и ответы пользователей не публикуются.

## Локальная сборка

Исходные JSON должны находиться в `kata-academy-export/`.

```powershell
npm run build
npm run check
```

Готовый сайт создаётся в `docs/` и не требует серверной части.
