# Персональный курс QA

Статическая учебная библиотека по ручному тестированию и MQA Base.

В публичную сборку входят только очищенные страницы, навигация и локальный поисковый индекс. Исходные JSON, служебные скрипты выгрузки, данные сессии и ответы пользователей не публикуются.

## Локальная сборка

Исходные JSON должны находиться в локальном каталоге выгрузки с окончанием имени `-academy-export`. Этот каталог не входит в Git.

```powershell
npm run build
npm run check
```

Готовый сайт создаётся в `docs/` и не требует серверной части.
