Лекция «REST: что это и как это работает»

 

Что такое REST?

REST (Representational State Transfer) — это архитектурный стиль, который определяет правила для взаимодействия между клиентом и сервером. REST не является протоколом, как SOAP, а представляет собой набор принципов, которые упрощают и делают гибкой передачу данных. В REST данные представлены как ресурсы, каждый из которых доступен по уникальному URL.

REST работает поверх протокола HTTP и позволяет клиенту получать или отправлять данные на сервер, используя понятные запросы. Данные передаются в различных форматах, чаще всего в JSON (популярен благодаря своей простоте) или XML (используется реже и более громоздкий).

 

Архитектурный стиль: что это и как понимать

Архитектурный стиль — это совокупность принципов, которые определяют, как компоненты системы взаимодействуют друг с другом. Он задаёт "рамки", но позволяет разработчикам выбирать конкретные способы реализации.

Пример: Представьте, что архитектурный стиль — это планировка квартиры.

  • Стиль задаёт общие принципы: где будет кухня, гостиная и ванная, какие комнаты должны быть соединены.

  • Но как именно будет выглядеть мебель, какого она цвета, и где она будет стоять, решают владельцы.

REST работает аналогично: он определяет, как клиент и сервер должны взаимодействовать (например, через HTTP, используя стандартные методы), но детали реализации остаются на усмотрение разработчиков.

 

Как работает REST?

  1. Клиент отправляет запрос. Например, мобильное приложение запрашивает список товаров в интернет-магазине. Запрос отправляется на сервер по определённому адресу (URL).

  2. Сервер обрабатывает запрос. Сервер анализирует запрос, выполняет необходимую операцию (например, извлекает данные из базы) и готовит ответ.

Сервер возвращает ответ. Ответ формируется в формате данных (обычно JSON) и отправляется клиенту. Например, клиент получает список товаров в виде:

[

    { "id": 1, "name": "Телефон", "price": 50000 },

    { "id": 2, "name": "Ноутбук", "price": 70000 }

]

 

Клиент отображает эти данные в удобном для пользователя виде.

 

Почему REST стал таким популярным?

  1. Простота. REST понятен, легко читаем и не требует сложных инструментов для работы. Можно отправлять запросы прямо из браузера или через инструменты вроде Postman.

  2. Гибкость. REST можно использовать в мобильных, веб-приложениях, и даже в IoT-устройствах. Он подходит практически для любых задач.

  3. Разные форматы данных. REST поддерживает JSON, XML, и даже простые текстовые файлы. JSON стал стандартом из-за своей компактности и удобства.

  4. Широкая поддержка. Почти все современные приложения используют REST, что делает его изучение полезным и востребованным.

 

Итог

REST — это современный стандарт для общения между клиентом и сервером. Благодаря своей простоте, гибкости и широкому использованию, он стал основой для большинства веб-приложений.

Для тестировщика важно понимать, как REST работает, знать, что данные чаще всего передаются в JSON, и уметь проверять запросы и ответы, используя инструменты вроде Postman. Эти знания помогут вам уверенно тестировать API и выявлять ошибки в их работе.

 

 

Что нужно уметь рассказать
– Термин «REST»
– REST = архитектурный стиль, а не протокол
– Работает поверх HTTP, использует стандартные методы (GET, POST, PUT, DELETE и др.)
– Данные чаще всего в JSON, реже XML
