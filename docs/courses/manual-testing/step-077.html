Лекция «JSON: основной формат передачи данных»

Сети · REST

JSON (JavaScript Object Notation) — это универсальный текстовый формат для хранения и обмена данными между системами. Он используется в большинстве современных приложений, особенно для работы с API. JSON отличается простотой, компактностью и гибкостью, что сделало его стандартом для передачи данных в интернете.

Что такое JSON и зачем он нужен?

JSON был создан как лёгкий и читаемый формат, который позволяет структурировать данные. Его основная задача — передавать информацию в удобной для человека и машины форме.

Пример: клиент (например, мобильное приложение) отправляет запрос на сервер, чтобы получить данные о продуктах. Сервер возвращает ответ в формате JSON:

{

  "products": [

    { "id": 1, "name": "Ноутбук", "price": 50000 },

    { "id": 2, "name": "Смартфон", "price": 30000 }

  ]

}

Этот ответ легко обрабатывается программой и отображается пользователю.

Формат JSON

JSON организует данные с помощью двух ключевых структур:

  1. Объекты:

    • Представляют собой набор пар "ключ: значение", заключённых в фигурные скобки { }.

    • Ключ всегда строка в двойных кавычках.

    • Значение может быть любого типа: строкой, числом, логическим значением, массивом, объектом или null.

Пример объекта:

{

  "name": "Иван",

  "age": 30,

  "isMarried": true

}

  1. Массивы:

    • Это упорядоченные списки значений, заключённые в квадратные скобки [ ].

    • Элементы массива нумеруются с 0.

    • Массивы могут содержать любые типы данных, включая вложенные массивы и объекты.

Пример массива:

[

  "Москва",

  "Санкт-Петербург",

  "Казань"

]

JSON позволяет комбинировать объекты и массивы, создавая вложенные структуры данных любой сложности.

Пример комбинированной структуры:

{

  "products": [

    { "id": 1, "name": "Ноутбук", "price": 50000 },

    { "id": 2, "name": "Смартфон", "price": 30000 }

  ],

  "totalProducts": 2

}

Более детальный разбор объектов, массивов и поддерживаемых типов данных мы изучим в следующей теме.

Почему JSON так популярен?

  1. Простота. JSON легко читается и пишется. Даже новички могут быстро понять его структуру.

  2. Компактность. JSON занимает меньше места, чем XML, благодаря отсутствию громоздких тегов, что делает его более быстрым для передачи.

  3. Широкая поддержка. JSON работает с большинством языков программирования и широко используется в веб-разработке.

  4. Гибкость. JSON поддерживает вложенность, что позволяет описывать сложные структуры данных.

Как JSON используется в API?

JSON — это стандартный формат передачи данных в REST API. Клиент отправляет запросы с параметрами в JSON, а сервер возвращает ответы в том же формате.

Пример взаимодействия:

Клиент отправляет запрос: {

  "product": "Кофемашина",

  "quantity": 2

}

Сервер отвечает: {

  "orderId": 12345,

  "status": "confirmed"

}

Итог

JSON — это лёгкий, универсальный и удобный формат для работы с данными. Его простота и гибкость сделали его стандартом для передачи информации в большинстве современных приложений. JSON — это фундамент, который нужно освоить, чтобы эффективно работать с API и разрабатывать качественные тесты.

Что нужно уметь рассказать
– Термин «JSON (JavaScript Object Notation)»
– Структуры: объекты { } и массивы [ ]
– Поддерживаемые типы: строка, число, логический, null, объект, массив
– Используется в REST API как стандартный формат
– Отличие от XML: компактность и простота
