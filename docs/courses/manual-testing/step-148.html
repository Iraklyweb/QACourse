Лекция «Шпаргалка по основным операторам SQL»

 

 

1. Операторы определения данных (Data Definition Language, DDL)

 

●      CREATE создаёт объект базы данных (саму базу, таблицу, представление, пользователя и так далее)

●      ALTER изменяет объект

●      DROP удаляет объект

 

2. Операторы манипуляции данными (Data Manipulation Language, DML)

 

●      INSERT добавляет новые данные

●      UPDATE изменяет существующие данные

●      DELETE удаляет данные

●      SELECT выбирает данные, удовлетворяющие заданным условиям

 

2.1 INSERT

 

INSERT [INTO] имя_таблицы [(список_столбцов)] VALUES (значение1, значение2, ... значениеN)

 

Пример:

INSERT Products(ProductName, Manufacturer, ProductCount, Price)

VALUES ('iPhone X', 'Apple', 5, 76000);

 

2.2 UPDATE

 

UPDATE имя_таблицы

SET столбец1 = значение1, столбец2 = значение2, ... столбецN = значениеN

[WHERE условие_обновления]

 

Пример:

UPDATE Products

SET Price = Price + 3000;

 

2.3 DELETE

 

DELETEFROM имя_таблицы

[WHERE условие_удаления]

 

Пример:

DELETEFROM Products

WHERE Manufacturer='Apple'AND Price < 60000;

 

2.4 SELECT

 

SELECT список_столбцов FROM имя_таблицы

 

* для выбора всех столбцов

AS - для определения псевдонима выходного столбца

 

Для фильтрации данных в команде SELECT применяется оператор WHERE, после которого указывается условие:

WHERE условие

 

В SQL можно использовать следующие логические операторы:

●        выражение1AND выражение2 (логическое И)

●        выражение1OR выражение2 (логическое ИЛИ)

●        NOT выражение (логическое отрицание)

 

Пример:

SELECT*FROM Products

WHERE Manufacturer ='Samsung'OR Price >50000

 

●      DISTINCTдля выбора уникальных значений по определенным столбцам

 

Пример:

SELECTDISTINCT Manufacturer FROM Products;

 

●      IN определяет набор значений, которые должны иметь столбцы:

WHERE выражение [NOT] IN (выражение)

 

Пример:

SELECT * FROM Products

WHERE Manufacturer IN ('Samsung', 'HTC', 'Huawei');

 

●      BETWEEN определяет диапазон значений с помощью начального и конечного значения, которому должно соответствовать выражение:

WHERE выражение [NOT] BETWEEN начальное_значение AND конечное_значение

 

Пример:

SELECT * FROM Products

WHERE Price BETWEEN20000AND50000;

 

●      LIKE принимает шаблон строки, которому должно соответствовать выражение:

WHERE выражение [NOT] LIKE шаблон_строки

 

Пример:

SELECT * FROM Products

WHERE ProductName LIKE'iPhone%';

 

●      ORDER BY сортирует значения по одному или нескольких столбцам:

●      DESC задаёт сортировку по убыванию

●      ASC задаёт сортировку по возрастанию

 

Пример:

SELECT ProductName, ProductCount

FROM Products

ORDERBY ProductCount DESC;

 

●      LIMIT позволяет извлечь определенное количество строк:

LIMIT [offset,] rowcount

 

Пример:

SELECT * FROM Products

LIMIT 2, 3;

 

3. Агрегатные функции

 

●      AVG вычисляет среднее значение

 

Пример:

SELECTAVG(Price) FROM Products

 

●      SUM вычисляет сумму значений

 

Пример:

SELECTSUM(ProductCount) FROM Products

 

●      MIN вычисляет наименьшее значение

●      MAX вычисляет наибольшее значение

 

Пример:

SELECTMIN(Price), MAX(Price) FROM Products

 

●      COUNT вычисляет количество строк в запросе

 

Пример:

SELECTCOUNT(Manufacturer) FROM Products

 

4. Операторы группировки

 

●      GROUP BY определяет, как строки будут группироваться

●      HAVING позволяет выполнить фильтрацию групп, то есть определяет, какие группы будут включены в результирующий набор

 

SELECT столбцы

FROM таблица

[WHERE условие_фильтрации_строк]

[GROUPBY столбцы_для_группировки]

[HAVING условие_фильтрации_групп]

[ORDERBY столбцы_для_сортировки]

 

Пример:

SELECT Manufacturer, COUNT(*) AS ModelsCount

FROM Products

GROUPBY Manufacturer

HAVINGCOUNT(*) > 1

 

5. Виды JOIN-ов

 

●      INNER JOIN

 

Пример:
SELECT столбцы

FROM таблица1

[INNER] JOIN таблица2

ON условие1

[[INNER] JOIN таблица3

ON условие2]

 

●      LEFT OUTER JOIN

●      RIGHT OUTER JOIN

 

Пример:
SELECT столбцы

FROM таблица1

{LEFT|RIGHT} [OUTER] JOIN таблица2ON условие1

[{LEFT|RIGHT} [OUTER] JOIN таблица3ON условие2]...

 

●      FULL OUTER JOIN
 

Пример:

SELECT*

FROM table1

FULLOUTERJOIN table2 ON table1.parameter=table2.parameter

 

●      SELF JOIN
 

Пример:

SELECT*FROM products JOIN products ON products.product=products.brand

 

●      CROSS JOIN


Пример:

SELECT*

FROMtable1

CROSSJOINtable2
