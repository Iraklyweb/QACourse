Лекция «SQL и собеседования»

 

SQL — одна из тем, которая может быть затронуты на собеседовании. Изученные SQL команды — это базовый минимум, который поможет вам чувствовать себя уверенно. На собеседовании вас не всегда будут спрашивать обо всех SQL командах. Вместо этого могут задать вопросы о том, как вы работали с базами данных. Если от вас ожидается высокий уровень навыков в SQL, это будет указано в вакансии или уточнено HR. Однако такие вакансии встречаются редко. В большинстве случаев SQL используется для проверки базовых знаний и навыков работы с данными.

 

Задачи по SQL часто включают 1-3 запроса, например, выборку данных с использованием JOIN, работу с WHERE или GROUP BY. Также могут быть вопросы по 1 INSERT или UPDATE. Главное — показать, как вы применяли SQL на практике и для чего использовали базы данных.

 

Часто задаваемый вопрос на собеседовании — с какой БД работали. Обычно это означает СУБД (система управления базами данных), но для простоты чаще используется сокращение "БД". Это может быть PostgreSQL, MySQL, Oracle и другие. Ответьте на этот вопрос, указав название БД, с которой работали, без необходимости уточнять что это СУБД.

 

Кроме того, вам могут спросить, работали ли вы напрямую через командную строку. Обычно для работы с БД используют такие инструменты, как DBeaver или PgAdmin, которые упрощают взаимодействие с базой данных. Лучше сразу уточнить, что использовали такие инструменты, чтобы избежать дополнительных неудобных вопросов.

 

HR может спросить, как вы оцениваете свой навык владения SQL. Ваш ответ может быть таким: "А как оценить навыки, у всех своя оценка. Я могу писать джоины и делать различные выборки. Этого достаточно?"

 

Когда HR спрашивает, как часто вы работаете с БД, правильный ответ: "Минимум 2-3 раза в неделю". Если вы скажете меньше, HR может посчитать, что ваш навык недостаточно развит и у вас нет достаточного опыта работы с БД.

 

Еще могут спросить, работали ли вы с NoSQL базами данных. Не стоит переживать, если у вас нет такого опыта, так как этот вопрос задают не так часто. Отсутствие опыта работы с NoSQL не является критичным.

 

Имеется смысл иметь общее представление о том, что такое NoSQL базы данных. Знания команд для работы с ними не обязательны — они легко гуглятся при необходимости. Основной фокус собеседования будет на вашем общем понимании принципов работы с данными, а не на глубоком знании конкретных технологий.

 

Часто задаваемые вопросы на собеседовании по SQL и базам данных:

  1. Что такое SQL? SQL (Structured Query Language) — это язык структурированных запросов, используемый для работы с реляционными базами данных. SQL позволяет извлекать, изменять, вставлять и удалять данные из базы данных.

  2. Что такое СУБД? СУБД (система управления базами данных) — это программное обеспечение, которое позволяет создавать, поддерживать, управлять и взаимодействовать с базами данных, обеспечивая структуру для хранения данных и механизмы их обработки. Примеры: MySQL, PostgreSQL, Oracle.

  3. Чем SQL отличается от MySQL? SQL — это стандартный язык, а MySQL — это одна из реализаций СУБД, которая использует этот стандарт.

  4. Какие бывают типы баз данных? Существуют реляционные и нереляционные базы данных. Реляционные БД хранят данные в таблицах (например, MySQL, PostgreSQL), а нереляционные — используют другие структуры, такие как документы или графы (например, MongoDB, Neo4j).

  5. Что такое реляционные и нереляционные базы данных? Реляционные базы данных (РБД) используют таблицы для хранения данных, которые связаны между собой с помощью ключей. Нереляционные базы данных не используют таблицы и часто применяют другие модели данных, такие как документы, графы или ключ-значение.

  6. Что такое первичный ключ (Primary Key) и внешний ключ (Foreign Key)?

    • Primary Key — это уникальный идентификатор записи в таблице. Он гарантирует, что каждая строка в таблице уникальна.

    • Foreign Key — это поле, которое ссылается на первичный ключ другой таблицы. Это создает связь между таблицами.

  7. Что такое JOIN? Какие виды JOIN существуют? JOIN — это операция, которая объединяет строки из двух или более таблиц на основе связанного столбца.

    • INNER JOIN — возвращает только те строки, которые есть в обеих таблицах.

    • LEFT JOIN (или LEFT OUTER JOIN) — возвращает все строки из левой таблицы и совпадающие строки из правой.

    • RIGHT JOIN (или RIGHT OUTER JOIN) — возвращает все строки из правой таблицы и совпадающие строки из левой.

    • FULL JOIN — возвращает строки, которые есть в обеих таблицах, а также строки, которых нет в одной из таблиц.

  8. Что такое DDL, DML, DCL, TCL? Какие команды туда входят?

    • DDL (Data Definition Language) — язык определения данных, используется для создания и изменения структуры базы данных. Примеры команд: CREATE, ALTER, DROP.

    • DML (Data Manipulation Language) — язык манипуляции данными, используется для работы с данными в базе. Примеры команд: SELECT, INSERT, UPDATE, DELETE.

    • DCL (Data Control Language) — язык управления доступом к данным. Примеры команд: GRANT, REVOKE.

    • TCL (Transaction Control Language) — язык управления транзакциями. Примеры команд: COMMIT, ROLLBACK, SAVEPOINT.

  9. Что такое агрегатные функции? Агрегатные функции выполняют вычисления на наборе данных и возвращают одно значение. Примеры агрегатных функций:

    • COUNT() — подсчитывает количество строк.

    • SUM() — вычисляет сумму значений.

    • AVG() — находит среднее значение.

    • MIN() — находит минимальное значение.

    • MAX() — находит максимальное значение.

 

Эти вопросы охватывают базовые и важные понятия, которые могут встретиться на собеседовании по SQL и работе с базами данных.
