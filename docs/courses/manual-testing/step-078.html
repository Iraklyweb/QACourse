Лекция «Формат JSON»

 

JSON организует данные с помощью объектов и массивов, которые могут содержать различные типы данных. Разберём всё подробно и структурированно.

 

1. Объекты

Объект в JSON — это структура данных, заключённая в фигурные скобки { }.

  • Объект состоит из пар "ключ: значение".

  • Ключ — всегда строка, заключённая в двойные кавычки.

  • Значение может быть любого типа: строки, числа, логического значения, массива, вложенного объекта или null.

Объекты используются для описания сущностей с их характеристиками (например, пользователя, продукта, адреса).

Пример объекта:

{

  "name": "Иван",

  "age": 30,

  "isMarried": true,

  "birthDate": "1993-05-20",

  "address": {

    "city": "Москва",

    "zip": 123456

  }

}

Разберём:

  • "name": "Иван" — ключ name связан со строкой "Иван".

  • "age": 30 — ключ age связан с числом 30.

  • "isMarried": true — ключ isMarried связан с логическим значением true.

  • "birthDate": "1993-05-20" — ключ birthDate содержит строку, представляющую дату в формате ISO 8601 (гггг-мм-дд).

  • "address" — вложенный объект, описывающий адрес с полями city и zip.

 

Вложенные объекты:

Объект может содержать другие объекты. Это позволяет описывать сложные структуры.

Пример вложенного объекта:

{

  "company": {

    "name": "TechCorp",

    "location": {

      "city": "Москва",

      "street": "Ленина, 10"

    }

  }

}

  • В объекте "company" есть вложенный объект "location", описывающий местоположение.

 

2. Массивы

Массив — это упорядоченный список значений, заключённый в квадратные скобки [ ].

  • Каждый элемент массива имеет индекс, начиная с 0 (нулевая нумерация).

  • Элементы массива могут быть разных типов: строки, числа, объекты, массивы или даже null.

  • Вложенные массивы и объекты позволяют описывать данные любой сложности.

Массивы используются для представления списков однотипных данных (например, список пользователей, навыков или городов).

Простой массив:

["Москва", "Санкт-Петербург", "Казань"]

  • Индекс 0: "Москва".

  • Индекс 1: "Санкт-Петербург".

  • Индекс 2: "Казань".

Массив объектов:

Массив может содержать объекты. Это удобно для описания списков сложных данных.

[

  { "city": "Москва", "population": 12506468 },

  { "city": "Санкт-Петербург", "population": 5351935 }

]

  • Первый элемент массива: объект с данными о Москве.

  • Второй элемент массива: объект с данными о Санкт-Петербурге.

Вложенные массивы:

Массив может содержать другие массивы, что позволяет описывать многоуровневые списки.

[

  ["Python", "Java", "SQL"],

  ["C++", "Go", "Rust"]

]

  • Первый элемент: массив языков программирования первой группы.

  • Второй элемент: массив языков второй группы.

 

Типы данных в JSON

JSON поддерживает шесть типов данных:

  1. Строка (String):

    • Текстовые данные, заключённые в двойные кавычки.

    • Может содержать буквы, цифры и специальные символы.

Пример: "name": "Анна"

  1. Число (Number):

    • Может быть целым (25) или дробным (3.14).

    • Также используется для представления дат в виде числа (например, UNIX timestamp).

Пример: "price": 499.99

  1. Логическое значение (Boolean):

    • Логическое выражение: true (истина) или false (ложь).

Пример: "isAvailable": true

  1. Объект (Object):

    • Набор пар "ключ: значение".

Пример: "address": {

  "city": "Москва",

  "zip": 123456

}

  1. Массив (Array):

    • Упорядоченный список значений.

Пример: "skills": ["Python", "Java", "SQL"]

  1. Null:

    • Специальное значение, обозначающее отсутствие данных.

    • null и "null" — разное, первое как null (ничего), второе как "строка"

Пример: "spouse": null

 

Пример JSON с комбинированными структурами:

{

  "id": 101,

  "name": "Иван",

  "age": 30,

  "skills": ["Java", "Python", "SQL"],

  "projects": [

    { "name": "CRM", "duration": 12 },

    { "name": "E-commerce", "duration": 8 }

  ],

  "isEmployed": true,

  "spouse": null

}

  • Поле "skills" содержит массив строк.

  • Поле "projects" содержит массив объектов, описывающих проекты.

 

Форматы дат, с которыми вы встретитесь на работе

При тестировании API вы часто будете работать с датами и временем. В разных системах могут использоваться разные форматы:

Date (Дата, без времени)

Представляет только дату без указания времени. Пример:

"date": "2024-02-06"

Используется для обозначения дней, например, даты регистрации или срока действия подписки.

 

  1. DateTime (Дата и время)

Содержит дату и точное время, обычно в формате ISO 8601. Пример:

"datetime": "2024-02-06T15:30:00Z"

Здесь T разделяет дату и время, а Z означает, что время указано в UTC.

  1. Timestamp (Метка времени)

Числовое представление времени в секундах или миллисекундах с 1 января 1970 года (Unix-время). Пример:

"timestamp": 1707223800

Используется в журналах учета событий (логах) и системах, где важно точное время события.

Эти форматы важно уметь различать, так как API могут требовать разные представления даты и времени в запросах и ответах.

 

Итог

JSON поддерживает простые типы данных (строки, числа, логические значения, null) и сложные структуры (объекты, массивы). Благодаря вложенности объектов и массивов JSON способен описывать данные практически любой сложности. Нумерация в массивах начинается с нуля, что важно учитывать при обработке данных. JSON — это универсальный и мощный формат для работы с данными, особенно в контексте API.
