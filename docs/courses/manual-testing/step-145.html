Проверяемое задание «JOIN»

 

В заданиях этого модуля тебе предстоит отрабатывать написание запросов на специальном обучающем портале - https://www.sql-ex.ru 
Что нужно сделать:

  1. Войти на сайт https://www.sql-ex.ru
  2. Выбрать в меню Упражнения по SQL -> SELECT (обучающий этап)
  3. Решить задачи №№ 6, 9, 13, 14, 19, 21, 33, 50
  4. Для каждой задачи в google-документ добавить номер задачи, получившийся запрос и скриншот с портала (на скриншоте должно быть видно номер задачи, запрос, результат выполнения с отметкой “Правильно”). Пример скриншота:
     

▧ Изображение: иллюстрация 
 

Прикрепи ссылку на получившийся документ. Название файла должно содержать номер модуля, фамилию студента и название задания.
Пример: 7 модуль, Петров Иван, join. Перед отправкой не забудь проверить, что выдан доступ на просмотр. Дополнительно проверь, что у ментора есть доступ к истории изменений и комментариям. 

Для этого задания также засеки сколько времени ушло на решение и отметь эту информацию в том же документе.
