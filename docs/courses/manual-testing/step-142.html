В заданиях этого модуля тебе предстоит отрабатывать написание запросов на специальном обучающем портале - https://www.sql-ex.ru 
Что нужно сделать:

  1. Войти на сайт https://www.sql-ex.ru
  2. Выбрать в меню Упражнения по SQL -> SELECT (обучающий этап)
  3. Решить задачи №№ 15, 20, 22
  4. Для каждой задачи в google-документ добавить номер задачи, получившийся запрос и скриншот с портала (на скриншоте должно быть видно номер задачи, запрос, результат выполнения с отметкой “Правильно”). Пример скриншота:
     

▧ Изображение: иллюстрация
