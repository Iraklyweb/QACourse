Практическое задание №1

 

Ваша задача:

Создать JSON согласно данным требованиям. Значения любые согласно требованиям. Созданный JSON прислать в Google Таблицах.

Как сдавать ДЗ:
В Google Таблицу.
В первую строку — слово JSON.
В эту же колонку, во вторую строку, и в одну ячейку — весь JSON, целиком, в одну ячейку, который по заданию.
Пример: Фото

JSON

{ {"dasdasdata":{
"asdasd": {
"sdasd": "sdasd",
"asdasda": "asdasda",
"asdasdasd": "asdasdasd",
"asdasda": true
}}

 

Для более продуктивного усвоения информации не используйте различные JSON Валидаторы, AI - помощники. Только теорию и примеры из интернета.

Название поля

Тип данных

Описание

Ограничения/Правила

employees

Массив объектов

Массив объектов, каждый из которых представляет сотрудника компании.

Должен содержать как минимум одного сотрудника.

id

Число

Уникальный идентификатор сотрудника.

Уникальный для каждого сотрудника.

firstName

Строка

Имя сотрудника.

Макс. длина: 50 символов.

lastName

Строка

Фамилия сотрудника.

Макс. длина: 50 символов.

position

Строка

Должность сотрудника в компании.

Макс. длина: 100 символов.

email

Строка

Электронная почта сотрудника.

Должен быть действительным адресом.

isFullTime

Булевое

Статус, работающий ли сотрудник на полный рабочий день.

true — если на полный рабочий день, false — если на неполный.

hireDate

Строка (Дата)

Дата начала работы сотрудника в формате "YYYY-MM-DD".

Должен быть в формате ISO 8601.

salary

Число

Зарплата сотрудника.

Число с точностью до 2 знаков после запятой.

contactDetails

Объект

Объект с контактной информацией сотрудника.

Должен содержать поля: телефон и адрес.

phoneNumber

Строка

Номер телефона сотрудника.

Должен быть в международном формате.

address

Объект

Адрес сотрудника.

Должен содержать улицу, город и почтовый индекс.

street

Строка

Улица сотрудника.

Макс. длина: 100 символов.

city

Строка

Город сотрудника.

Макс. длина: 50 символов.

postalCode

Строка

Почтовый индекс сотрудника.

Должен быть валидным почтовым индексом.

 

Формат сдачи:

Используйте предоставленный шаблон для сдачи ДЗ Шаблон.

 

Необходимо скопировать файл себе:

  1. Файл > Создать копию

  2. На листе "Техническая инфа" заполнить колонку "Репортер" любыми данными (опционально)

  3. Для удобства колонка "ID" автоматически заполняется.

Все последующие домашние задания, до особого распоряжения, выполняем в копии созданного шаблона

 

Сдавать домашнее задание можно только в Google Таблицах. Задания, отправленные в других форматах (Excel, Word и т.д.), приниматься не будут. Убедитесь, что вы правильно организовали свою работу и предоставили доступ к документу. Это обязательное условие для сдачи урока.

 

Инструкция, как в Google Таблицах дать доступ:

  1. Нажать "Настройки доступа". В правом верхнем углу

  2. Назовите согласно шаблону: Название модуля, Номер задания, Фамилия Имя. Например, "1.6 Практика. Задание 1. Иванов Иван"

  3. Нажать "Сохранить"

  4. В разделе "Общий доступ" сменить "Доступ ограничен" на "Все, у кого ссылка"

  5. "Читатель" заменить на "Редактор"

  6. Нажать "Готово"
