Ваша задача:

Необходимо найти дефекты в JSON и поправить его. Исправленную версию можно передать JSON-файлом, вставить в документ или предоставить по ссылке.

Как оформить результат:
Передайте JSON удобным способом: отдельным файлом, кодом в документе или ссылкой. Главное, чтобы весь JSON был виден целиком, сохранял форматирование и его можно было скопировать для проверки.

JSON

{ {"dasdasdata":{
"asdasd": {
"sdasd": "sdasd",
"asdasda": "asdasda",
"asdasdasd": "asdasdasd",
"asdasda": true
}}

Помимо исправленной JSON в свободной форме указать, где были проблемы.

Для более продуктивного усвоения информации не используйте различные JSON Валидаторы, AI - помощники. Только теорию и примеры из интернета.

Как оформить результат:

При желании используйте предоставленный шаблон для оформления работы Шаблон.

Если хотите работать в шаблоне, создайте свою копию:

  1. Файл > Создать копию

  2. На листе "Техническая инфа" заполнить колонку "Репортер" любыми данными (опционально)

  3. Для удобства колонка "ID" автоматически заполняется.

Этот шаблон можно использовать и для следующих заданий, если вам так удобнее.

Оформите результат в удобном для вас виде: например, в Google Таблицах, Excel, текстовом документе или другом понятном формате. Главное, чтобы структура работы хорошо читалась. Если делитесь ссылкой, убедитесь, что материал открывается для просмотра.
