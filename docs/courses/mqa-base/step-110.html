Лекция «Попарное тестирование»

Техники тест-дизайна · Теоретические сведения

Попарное тестирование

Попарное тестирование — это техника тест-дизайна, при которой проверяются все возможные пары параметров хотя бы один раз.

Метод используется, когда комбинаций слишком много, и полный перебор нецелесообразен. Вместо проверки всех вариантов тестировщик концентрируется на взаимодействии параметров попарно, потому что большая часть дефектов проявляется именно на стыке двух значений.

Пример:

Есть три параметра фильтра — размер, цвет и тип товара.

  • Размер: S, M, L, XL
  • Цвет: Красный, Синий, Зелёный
  • Тип: Одежда, Обувь

Полный перебор даёт 4×3×2 = 24 комбинации.

Попарное тестирование сокращает их примерно до 12, сохраняя покрытие всех пар.

Один тест, например “S + Красный + Одежда”, закрывает сразу три пары:

  • S + Красный
  • S + Одежда
  • Красный + Одежда

То есть цель — не пройти все возможные сценарии, а убедиться, что каждая пара параметров была проверена хотя бы один раз.

На практике метод применяют, когда:

  • — у функции есть несколько входных параметров (настройки, фильтры, конфигурации);
  • — параметры могут влиять друг на друга;
  • — полный перебор значений приведёт к сотням или тысячам тестов.

Пример:

Кофемашина имеет параметры:

  • Размер чашки — Маленькая, Средняя, Большая
  • Тип напитка — Эспрессо, Американо
  • Молоко — Без молока, С молоком
  • Сахар — Без сахара, С сахаром

Полный перебор = 3×2×2×2 = 24 комбинации.

Попарное тестирование даёт 6–8 тестов, которые закрывают все пары.

Например:

  • Маленькая + Эспрессо + Без молока + Без сахара
  • Средняя + Американо + С молоком + С сахаром
  • Большая + Эспрессо + С молоком + Без сахара
  • Маленькая + Американо + Без молока + С сахаром
  • Средняя + Эспрессо + Без молока + С сахаром
  • Большая + Американо + С молоком + Без сахара

Каждая пара параметров встречается хотя бы раз — этого достаточно, чтобы выявить дефекты на уровне взаимодействия настроек.

Попарное тестирование применяют в системах с множеством зависимых параметров: фильтры, конфигурации, настройки окружения, товары с вариантами характеристик.

Метод экономит время, снижает избыточность тестов и позволяет удерживать охват без потери глубины.

Для автоматизации подбора комбинаций используются инструменты вроде Pairwise Testing Tool, AllPairs или PICT — они подбирают минимальный набор тестов, покрывающий все пары.
