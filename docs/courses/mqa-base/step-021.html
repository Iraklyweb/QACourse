Лекция «Стенд / Среда»

Тестовая документация · Состояние документа

Стенд / Среда

Стенд — конкретная копия продукта, на которой выполняются проверки и воспроизводятся дефекты: Dev, Stage, PreProd, Prod или другие.

Он выглядит и работает так же, как основная версия, только используется отдельно от боевой среды.

Это позволяет тестировать функциональность без влияния на реальных пользователей и данные.

Стенды отличаются по назначению и уровню стабильности.

Обычно их несколько: один используется для тестовых задач, другой — для финальных проверок перед релизом, третий — это уже рабочая версия.

По названию стенда можно понять, где выполнялась проверка и на каком уровне был найден дефект.

Пример заполнения:

— Test — общий стенд для проверки задач.

— Stage — стенд, максимально приближённый к боевому.

— Prod — боевая версия, доступная пользователям.

Названия могут отличаться, но смысл один — по стенду должно быть ясно, где выполнялась проверка или воспроизводился баг.

Если это не указано, теряется контекст, и команде сложнее понять, где искать проблему и где перепроверять исправление.

На некоторых проектах стенд может быть только один — например, единая тестовая среда или обособленный инстанс продукта.

В таких случаях поле можно не заполнять: смысл теряется, когда выбора нет.

Главное — чтобы команда одинаково понимала, где именно происходила проверка.
