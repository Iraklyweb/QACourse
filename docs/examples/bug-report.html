Заголовок
Двойное нажатие «Подтвердить заказ» создаёт два одинаковых заказа
Окружение
Test; сборка 2.4.0; Chrome 130; Windows 11
Предусловия
Пользователь авторизован; в корзине один доступный товар; заполнены данные доставки

Шаги воспроизведения

  1. Открыть корзину.
  2. Перейти к оформлению заказа.
  3. Дважды быстро нажать «Подтвердить заказ».
  4. Открыть историю заказов.
Фактический результат

Созданы два заказа с одинаковым составом и разными номерами.

Ожидаемый результат

После первого нажатия кнопка блокируется и создаётся только один заказ.

Вложения: видео воспроизведения и два идентификатора заказов без персональных данных.

Разбор структурыПочему отчёт воспроизводим
  • ЗаголовокСодержит действие, условие и наблюдаемую проблему.
  • ОкружениеПоказывает, где именно обнаружен дефект.
  • ШагиНачинаются после предусловий и приводят к проблеме без лишних действий.
  • Фактический результатОписывает наблюдаемое поведение без предположений о причине.
  • Ожидаемый результатФиксирует корректное поведение системы.
