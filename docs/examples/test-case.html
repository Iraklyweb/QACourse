Заполненный примерКак выглядит документ
ID
TC-ORDER-001
Приоритет
Высокий
Название
Успешное оформление заказа авторизованным пользователем
Цель
Убедиться, что пользователь может оформить один товар с доставкой курьером
Предусловия
Пользователь авторизован; товар «Беспроводная мышь» доступен; корзина пуста
Тестовые данные
Адрес: Учебная улица, 10; способ оплаты: при получении
№ДействиеОжидаемый результат
1Открыть карточку товара «Беспроводная мышь»Карточка открыта, товар доступен для заказа
2Нажать «Добавить в корзину»Товар добавлен, счётчик корзины равен 1
3Открыть корзинуОтображается один товар, название и цена верны
4Нажать «Оформить заказ», указать адрес и оплату при полученииДанные приняты, кнопка подтверждения доступна
5Нажать «Подтвердить заказ»Создан один заказ, показан его номер и статус «Принят»

Постусловие: удалить учебный заказ или пометить его как тестовый.

Разбор структурыЗачем нужны поля
  • НазваниеОписывает проверку и ожидаемый итог без чтения шагов.
  • ПредусловияФиксируют состояние системы до первого действия.
  • Тестовые данныеПозволяют повторить проверку в тех же условиях.
  • ШагиСодержат по одному понятному действию в правильной последовательности.
  • Ожидаемый результатДаёт критерий успешности для каждого шага.
